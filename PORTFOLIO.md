# About this source snapshot

This repository presents part of the DrownShieldAI implementation with a new Git history, for code review.

Included: the detection, tracking, behaviour-analysis, clustering, action-recognition and confirmation code; training and export scripts; the annotation review tools; the unit tests with their recorded-track fixtures; container packaging.

Not included: trained model weights, datasets and videos, the alerting and cloud integration, model encryption, device provisioning scripts, internal reports and logs. Local paths, camera credentials and cloud identifiers were replaced with placeholders or environment variables.

The code is published for review only. No licence to use, copy or deploy it is granted.
